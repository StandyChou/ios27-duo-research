01 · 先看结论

研发影响

这场发布会对普通 iOS App 的首要影响不是新硬件参数，而是 iPhone 从固定手机画布走向可折叠、可变尺寸和多显示面。

  1. 先处理启动与布局阻断。 用最新 SDK 构建时，UIKit App 必须采用基于 UIScene 的生命周期；固定屏幕、方向和对称安全区假设都需要审计。
  2. 把 iPhone Duo 当作连续尺寸环境。 布局依据 size class、scene bounds 和 safe area 变化，而不是设备型号或横竖屏；标准导航容器会自动适配。
  3. 重新检查组件层级与 Liquid Glass。 iOS 27 调整玻璃折射、对比度、字体与栏行为，用户还能改变玻璃外观强度，定制界面不能依赖固定透明度。
  4. 把 Siri AI 接入当作 App Intents 工程。 自然语言触达 App 内容与动作的公开路径是 App Intents、实体/意图 schema、View Annotations 和测试框架。
  5. 提前准备分发变化。 2027 年 4 月起提交的 iOS/iPadOS App 需要使用 iOS 27 / iPadOS 27 SDK；含社交媒体能力的 App 还需复核年龄分级答案。

02 · UI 与布局

组件

重点是组件在窗口变宽、设备折叠、系统栏移到侧边以及多显示面同时工作时的行为。

C01

连续尺寸与 Size Class

发布会已宣布SDK 已开放
功能细节
iPhone Duo 外屏接近常规 iPhone，内屏横向与纵向均为 regular size class；内屏不遵循 App 声明的 supported interface orientations。App 在 Duo、iPhone Mirroring 和 iPad 上都可能动态改变 scene 尺寸。
研发影响
使用 SwiftUI 环境或 UIKit trait collection 决定布局。不要用机型、idiom 或横竖屏推导可用空间；优先让同一信息架构在 compact/regular 间重排。
可用性
现有 App 可运行，但使用 iOS 27 与 27.1 SDK 后会逐步获得更完整的边到边和纵向栏布局。

Apple Developer Tech Talk：Prepare your app for iPhone Duo

C02

安全区、折痕与 Reserved Region

SDK 已开放
功能细节
Duo 的安全区可能左右不对称；铰链、相机和系统 UI 会形成 division 或 occlusion reserved regions。iOS 27.1 提供 SwiftUI ReservedRegion 与 UIKit UIViewReservedRegion 相关能力。
研发影响
前景交互内容应遵守每一侧的 safe area，背景可延伸到边缘。只在自定义沉浸式布局中查询 reserved regions；标准容器会自动避让。
可用性
Xcode 27.1 / iOS 27.1。折叠姿态和 reserved region 必须通过可用性检查与设备能力检测。

Apple Developer Tech Talk：Strike a pose with adaptive layouts

C03

纵向工具栏、标签栏与溢出

发布会已宣布SDK 已开放
功能细节
iPhone Duo 会把 App 导航和操作移到屏幕侧边，以保留纵向内容空间。系统栏与状态、Live Activities 共用垂直区域，空间不足时项目进入 overflow menu。
研发影响
优先使用系统 toolbar/tab bar；为关键动作设置 visibility priority，低频动作放入 overflow。图标优先于长文本，自定义 view 需为横向和纵向表示准备可替代布局。
可用性
iOS 27.1 SDK 提供完整纵向栏行为；确有不适配的重度自定义场景才考虑选择退出。

Apple Developer Tech Talk：Raise the bar with iPhone Duo

C04

导航、侧边栏与系统呈现

SDK 已开放
功能细节
NavigationSplitView、UISplitViewController、TabView 与 UITabBarController 可在折叠时收拢，在内屏以平铺或覆盖方式展示。Sheet、Popover、Context Menu 与 Alert 也会避开折痕并调整栏方向。
研发影响
先验证系统组件的自动行为，再改自定义布局。内屏可选择 sidebar，以两栏呈现层级和详情；不要为每种姿态复制一套导航树。
可用性
iOS 27/27.1 SDK。UIKit 可通过 sidebar availability 判断当前是否能展示侧边栏。

WWDC26：Modernize your UIKit app

C05

多显示面与多 Scene

SDK 已开放
功能细节
iPhone Duo 支持多窗口、多显示面、并排多任务、铰链角度观察和 scene accessory，可让补充内容跨内外屏呈现。
研发影响
UIScreen.main 在双显示设备上含义不明确并面临弃用风险。应从 windowScene 获取 screen、bounds 与 scale，并保证每个 scene 独立维护状态。
可用性
最新 SDK 提供 scene 和 hinge 相关接口；铰链数据适合交互效果，不应代替 safe area/布局 API。

Apple Developer Tech Talk：Leverage multiple displays and scenes

C06

Duo 相机与双屏取景

发布会已宣布SDK 已开放
功能细节
新相机体验包含内外摄像头、Virtual Front Camera、方向协调器和双显示面预览/控制。系统相机还展示 Kid Cue、Duo FaceTime 与支架式拍摄等设备能力。
研发影响
使用 AVCaptureDeviceDirectionCoordinator 跟踪折叠/翻转后的有效相机方向，按实际 preview aspect ratio 布局；不要固定镜头位置或旋转逻辑。
可用性
公开 Tech Talk 给出 API 方向；具体 device type 必须运行时检测，系统相机独占体验不能默认向第三方开放。

Apple Developer Tech Talk：Build a great camera experience

C07

Dynamic Island 与 Live Activities

发布会已宣布SDK 已开放
功能细节
Duo 的 Dynamic Island 位于内外屏侧边并纵向扩展，用于显示 Live Activities 与提醒；iPhone 18 Pro 的 Dynamic Island 也进一步缩小。
研发影响
ActivityKit 数据模型继续有效，但需要检查紧凑、最小、扩展和锁屏展示在新几何区域的可读性，不要用固定像素模拟系统岛。
可用性
ActivityKit 是公开框架；Duo 具体展示由系统决定。

ActivityKit 官方文档iPhone Duo Newsroom

C08

SwiftUI 组件与交互扩展

SDK 已开放
功能细节
SwiftUI 新增 toolbar visibility priority、固定低优先级 overflow、导航栏滚动最小化、任意容器重排、任意 ScrollView swipe actions，以及更完整的 Document API。
研发影响
高频编辑动作要明确优先级；自定义 List/Grid 拖拽与侧滑可统一到系统行为；文档型 App 可调研异步增量读写和直接磁盘访问。
可用性
Xcode 27 与对应 2027 平台 SDK；逐 API 做 availability 隔离。

SwiftUI What's NewSwiftUI Updates

C09

锁屏 WidgetKit 与系统渲染

SDK 已开放布局由系统决定
功能细节
锁屏使用 WidgetKit 的 accessory widget families。系统会按上下文选择 fullColor、accented 或 vibrant 渲染；App 可读取 widgetRenderingMode 与 isLuminanceReduced，并通过 containerBackgroundRemovable 声明背景是否可移除。
研发影响
同一组件要在锁屏、主屏、待机显示与不同强调色下保持信息层级。颜色不能承担唯一语义；背景被移除时仍需可读，AOD 降亮时应减少细节并验证刷新节奏。
能力边界
公开 API 支持内容和渲染适配，不支持第三方 App 任意摆放锁屏组件、强制两行自由布局、调整系统玻璃参数或移除系统 Now Playing。

03 · 视觉系统

主题

iOS 27 延续 Liquid Glass，并把重点从“更透明”调整为更稳定的可读性、适配性和用户控制。

T01

Liquid Glass 对比度与折射调整

发布会已宣布SDK 已开放
功能细节
iOS 27 通过更均匀的折射和更高对比度提升 Liquid Glass 可读性；系统 App 图标也变得更锐利、细节更多。
研发影响
使用系统材质和组件的 App 会自动获得更新。自绘玻璃、固定 blur 值或叠加自定义背景的界面需要重新对比，避免和系统调整互相干扰。
可用性
标准组件自动采用；自定义 SwiftUI 视图可使用 glassEffect(_:in:)。

iOS 27 官方功能页Applying Liquid Glass to custom views

T02

用户可调玻璃外观

发布会已宣布仅系统能力 / 暂无第三方 API
功能细节
系统新增滑杆，让用户在超清晰到完全着色之间调整 Liquid Glass 外观；SwiftUI 标准组件会自动响应。
研发影响
不要假设固定透明度、折射强度或背景亮度，也不要把信息含义只编码在玻璃层。应在系统外观变化、浅色/深色、增加对比度和降低透明度下验证。
可用性
用户侧设置已宣布；当前引用资料没有提供读取用户滑杆数值的第三方 API。

WWDC26：What's new in SwiftUI

T03

界面层与内容层分离

SDK 已开放
功能细节
Apple 建议把导航、标签栏、工具栏和全局动作视为熟悉的系统界面层，把品牌表达集中在下方内容层。
研发影响
优先使用原生导航尺寸、位置和交互；品牌色用于有意义的状态或主动作，定制字体需保证动态字号与可读性，自定义组件仍应遵循系统 Sheet、Popover 和边距规律。
可用性
设计指导，不要求单一框架。

WWDC26：Communicate your brand identity on iOS

T04

自定义 Glass 的边界

SDK 已开放
功能细节
SwiftUI 的 Glass 支持 regular、clear、identity、tint 与 interactive 配置；GlassEffectContainer 可组合并在几何变化时形变。
研发影响
仅给浮在内容之上的交互控件使用玻璃，不把整页内容套入玻璃。自定义 tint 必须与文字/图标前景色共同做对比度测试。
可用性
公开 SwiftUI API，需要按系统版本提供回退外观。

SwiftUI Glass 官方文档

T05

图标、字体与无障碍

SDK 已开放
功能细节
更新后的系统强调更精细图标、清晰命名、可缩放排版和一致的系统符号。VoiceOver、字幕和低视力工具在 iOS 27 也有增强。
研发影响
复核 SF Symbols 对齐、图标描边密度、Dynamic Type、VoiceOver 顺序、按钮可访问名称、字幕安全区与 200% 文本缩放。
可用性
设计与无障碍能力已公开；系统自动字幕不等同于 App 可跳过自身媒体字幕和无障碍实现。

04 · API 与平台

系统特性

以下内容同时覆盖发布会再次强调的 iOS 27 能力和同期开放的开发者技术，按“可集成”与“仅用户侧”区分。

S01

Siri AI 与 App Intents

发布会已宣布SDK 已开放
功能细节
Siri AI 可利用个人上下文、跨 App 执行动作并理解自然语言。App Intents 新增实体/意图 schema、View Annotations、Spotlight 语义索引和端到端 App Intents Testing。
研发影响
盘点可被发现的实体与低风险动作，定义稳定标识、参数、确认和错误结果；敏感或不可逆操作必须保持用户确认。使用测试框架验证真实系统路径。
可用性
Siri AI 于 iOS 27 首发时以英语 beta 推出，其他语言与地区分批支持；App Intents API 可按 SDK 文档集成。

App Intents 官方文档iOS 27 开发者总览

S02

Foundation Models 与多模态

SDK 已开放
功能细节
Foundation Models 统一 Apple 本地模型、兼容的云模型和其他 Language Model provider；多模态 prompt 可包含图片，并可调用 Vision 的 OCR、条码等工具。Dynamic Profiles 可在会话中切换模型、工具和指令。
研发影响
先做设备/模型可用性、隐私和降级设计，再建立质量、安全、延迟与成本评估。不要把 Siri AI 的系统个人上下文当作 App 默认可访问数据。
可用性
公开 Swift API；具体 Apple Intelligence 模型受设备、语言、地区和服务资格限制。

Foundation Models 官方文档iOS 27 开发者总览

S03

UIKit Scene 生命周期成为硬要求

SDK 已开放
功能细节
Apple 明确说明：使用最新 iOS 27 SDK 构建时，未采用基于 scene 生命周期的 App 将无法启动。
研发影响
把启动、窗口创建、URL/NSUserActivity 处理、状态恢复和前后台事件从 AppDelegate 迁移到 scene 体系，并覆盖多 scene 场景。
可用性
构建期强制变化，属于 P0 阻断项。

UIKit UpdatesWWDC26：Modernize your UIKit app

S04

SwiftUI 数据流与加载性能

SDK 已开放
功能细节
State 成为宏并让 class 状态在视图生命周期中惰性初始化；ContentBuilder 统一替代多个特定 builder；AsyncImage 默认遵守 HTTP 缓存头并允许定制 request/session。

S05

发布会已宣布仅系统能力 / 暂无第三方 API
功能细节
